# 產險保單數位特助系統

本專案為一款專為保險顧問設計的數位管理系統，旨在協助管理產險保單與旅平卡資訊，並自動化續保提醒與家庭保障分析流程。

## 系統架構

1. 資料庫層：以 Google Sheets 試算表作為主要的關聯式資料庫。
2. 後端邏輯：基於 Google Apps Script 平台，處理 JSON 資料同步、去重、家庭 Union-Find 自動分組，以及與試算表的讀寫互動。
3. 前端介面：單頁網頁應用程式（ HTML / CSS / JavaScript ），透過 `google.script.run` 進行非同步資料檢索，並支援精美保障圖卡生成與 LINE 續保提醒發送。

## 檔案結構

- `Code.gs` ：後端主程式腳本，負責選單建立、資料同步、分組演算法及 API 介面。
- `Index.html` ：前端使用者介面，提供響應式排版、智慧搜尋、圖卡 canvas 生成與社群分享功能。

## 部署與設定說明

1. 於 Google Sheets 建立對應工作表（保單主表、險種明細表、系統設定、原始資料、旅平卡主表、旅平卡被保人名冊、比對旅平卡覆蓋表、客戶稱呼表）。
2. 在「擴充功能」中開啟 Apps Script 編輯器。
3. 將本專案的 `Code.gs` 與 `Index.html` 內容複製入編輯器中。
4. 設定 `Code.gs` 頂部的 `CONFIG` 物件，填入您的試算表 ID 與 Google Drive 資料夾 ID 。
5. 部署為網頁應用程式，即可開始使用。
